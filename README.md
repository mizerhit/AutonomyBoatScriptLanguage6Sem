# Eye boat

**Eye boat** — это проект, реализующий управление лодкой на Python с использованием библиотеки CV2  для управления видео потоком. Этот проект демонстрирует архитектурный подход к разработке лодки без прямого управления благодаря машинному зрению.

---

## 📖 Описание проекта

Проект представляет собой лодку с камерами с такими функциями:
- Поиск объектов с заданными характеристиками.
- Движение к объектам.
- Интерактивное меню.
- Отображение информации о текущем состоянии процессов.
